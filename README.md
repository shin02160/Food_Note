# Place Notes v2.1

Notion의 실제 방문 기록을 읽어오는 독립 웹앱. 아이보리/세이지 톤, 모바일 대응, 한국어 UI. Node.js 20 이상(로컬 .env 자동 로딩은 22 권장), 외부 npm 패키지 없음.

## 실행
1. `npm start` → http://localhost:3000.
2. `.env.example`을 `.env`로 복사합니다. Notion 내부 통합에 콘텐츠 읽기 권한을 부여하고 Food Notes 데이터베이스를 연결한 뒤 `NOTION_TOKEN`을 입력합니다. 공유 링크를 사용하려면 32자 이상의 랜덤값을 `APP_SECRET`에 입력합니다.
3. 서버를 재시작합니다. 웹 주소에 접속한 누구나 로그인 없이 연결된 기록과 사진을 열람할 수 있습니다. 새로고침 버튼으로 최신 기록을 조회합니다. 기록 작성·수정·삭제는 Notion에서만 합니다.
4. `npm test`로 테스트 실행.

## Vercel 배포
새 비공개 GitHub 저장소에 이 폴더 내용을 업로드하고 Vercel에서 Import. Framework Preset Other, Root Directory는 프로젝트 루트, Output Directory `public`(vercel.json 설정). 환경변수 NOTION_TOKEN과 NOTION_DATA_SOURCE_ID를 입력한 뒤 Deploy합니다. 공유 링크를 사용하려면 APP_SECRET도 설정합니다. 실제 배포와 토큰 설정은 사용자의 계정에서 필요. 토큰과 APP_SECRET은 Git에 커밋하지 않습니다.

## 구현
- Notion API 2025-09-03 data source query, 100개 단위 페이지네이션, 최신순, 속성명 기반 매핑.
- 검색/지역/음식/재방문 필터, 지역 및 방문 통계, 카드/목록, 상세 사진 및 후기.
- 공유 링크는 7일 유효한 AES-256-GCM 암호화 스냅샷(서버 DB 추가 불필요), 1~10건 선택. 공개 페이지는 읽기 전용이며 Notion ID·사진·일상/여행 연결은 제외. 링크를 받은 누구나 열 수 있습니다. 간단 후기는 공유 응답에서 제외합니다. 개별 공유 취소 기능 없음; APP_SECRET 변경 시 모든 공유 링크 무효화. 긴 공유 링크는 일부 메신저에서 제한될 수 있음.
- Notion에 저장된 사진은 단기 유효 URL을 사용하며 만료 시 새로고침. 외부 이미지도 포함될 수 있음.
- Notion 연동 미설정, 조회 오류, 방문 기록 없음, 검색 결과 없음을 화면에 표시합니다.
- 공유 후 편집/삭제가 기존 공유 스냅샷에 반영되지 않음.

## 확인 사항
로컬 단위 테스트 및 HTTP 스모크 테스트는 실행 가능. 실제 Notion 통합 토큰과 배포 권한이 제공되지 않아 라이브 연동/배포 검증은 별도 필요. 기존 Notion DB와 기존 웹앱 코드는 변경하지 않음.

## v1.1 통계 및 지도 업데이트
- 방문 기록 / 통계 탭, 전체 또는 연월별 기간 선택, 지역·음식 종류·재방문 의사·월별 집계.
- 방문 건수는 레코드 수, 방문 매장 수는 정규화된 상호명+지역+세부 지역 조합으로 집계(동일 매장명이 다르게 입력된 경우 별도 집계 가능). 또 갈래 비율은 미입력 포함 전체 방문 건수 기준.
- 메뉴는 쉼표·세미콜론·줄바꿈으로 구분된 기록 문자열 기준이며, 한 방문 안에서 동일 메뉴 중복은 1건 처리한다. 메뉴 표기가 다르면 별도 집계한다. 메뉴 합계는 방문 수보다 클 수 있다.
- 통계 항목을 클릭하면 기간과 항목 조건이 적용된 방문 목록을 표시한다. 초기화 또는 방문 기록 탭으로 전체 목록 복귀.
- 상세 화면에 기존 Notion 주소, 네이버 지도, Google Maps 필드를 표시한다. 공개 공유 데이터 범위는 기존과 동일하며 통계 탭은 공유 화면에서 숨긴다.
- 기존 DB 속성을 재사용하므로 DB 변경 불필요. Notion 조회 후 클라이언트에서 집계한다.

## v1.2 목록 및 상세 화면

- 방문 기록은 기본 목록형으로 표시하며 카드 보기로 전환할 수 있습니다.
- 방문 기록을 누르면 상세 화면이 열립니다. 상세 주소를 새로고침해도 해당 기록이 열리며, 같은 세션에서 목록으로 돌아오면 검색·필터와 스크롤 위치가 복원됩니다.
- 상세 화면에서 방문 정보, 메뉴, 후기, 매장 위치, 사진을 볼 수 있습니다. 사진 확대 화면은 이전·다음 버튼과 키보드 방향키를 지원합니다.
- 공유 기능을 설정하면 목록에서 여러 건을 선택하거나 상세에서 해당 방문 한 건을 공유할 수 있습니다. 공유 상세에는 기존 공유 항목이 표시됩니다.

## v1.4 식당, 또 갈래, 갤러리

- 식당별로 묶인 목록과 방문 이력, 대표 재방문 의사 기준의 또 갈래 탭, 방문 사진 갤러리를 제공합니다.
- 갤러리는 지역·음식 종류·기간으로 필터링할 수 있으며, 확대 화면에서 식당 상세로 이동할 수 있습니다.
- 방문 및 식당 데이터 소스를 읽습니다. 같은 Notion 통합에 두 DB를 연결하세요. 방문 데이터 소스는 NOTION_VISIT_DATA_SOURCE_ID, 기존 NOTION_DATA_SOURCE_ID 순으로 설정할 수 있으며 식당 데이터 소스는 NOTION_RESTAURANT_DATA_SOURCE_ID로 지정할 수 있습니다. 동일한 기본 ID가 코드에 포함되어 있습니다.
- 앱으로 돌아오면 Notion 기록을 다시 읽습니다. 목록과 상세 화면의 새로고침 버튼으로 즉시 다시 조회할 수 있습니다.
- 상호명·지역·음식 종류·주소·지도·대표 재방문 의사는 식당 DB에서 관리합니다. 방문 날짜·메뉴·후기·사진·방문별 재방문 의사는 방문 이력 DB에서 관리합니다.
- 식당 DB 접근 권한이 없거나 방문에 식당 연결이 없으면 방문 이력에 저장된 정보를 표시합니다. 이 경우 대표 재방문 의사는 표시하지 않습니다.
- 공유할 식당을 선택하면 기존 공유 항목으로 해당 식당의 방문 이력을 묶습니다. 이전 공유 링크도 열 수 있습니다.

## Place Notes v2.1

- 방문 기록은 로그인 없이 볼 수 있습니다. 추천·관심 정보는 공개 장소 상세에서 표시합니다. 간단 후기, 미방문 장소, 위시 아이템, 여행 관계, 참고 자료는 비공개 보기에서 표시합니다. 비공개 보기는 16자 이상의 랜덤 APP_PASSWORD와 32자 이상의 APP_SECRET이 설정된 경우에만 열립니다.
- 브랜드는 Notion의 명시적 지점 관계를 기준으로 묶습니다. 지역과 필터에 맞는 지점을 카드에 집계하고, 브랜드 상세에는 현재 열람 가능한 모든 연결 지점을 표시합니다.
- 장소·방문 이력과 함께 브랜드·사진·위시 아이템 데이터 소스를 같은 Notion 통합에 연결할 수 있습니다. 선택 데이터 소스를 읽을 수 없으면 연결 안내와 함께 기존 기록을 표시합니다.
- 공유에는 실제 방문의 상호, 지역, 날짜, 메뉴, 구매품과 재방문 의사가 포함됩니다. 브랜드 ID, 주소, 지도, 사진, 위시 및 여행 정보는 포함되지 않습니다.
