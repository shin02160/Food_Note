# Food Notes v1.0

Notion의 실제 방문 기록을 읽어오는 독립 웹앱. 아이보리/세이지 톤, 모바일 대응, 한국어 UI. Node.js 20 이상(로컬 .env 자동 로딩은 22 권장), 외부 npm 패키지 없음.

## 실행
1. `npm start` → http://localhost:3000 (설정 전에는 가상의 샘플만 표시).
2. `.env.example`을 `.env`로 복사합니다. Notion 내부 통합에 콘텐츠 읽기 권한을 부여하고 Food Notes 데이터베이스를 연결한 뒤 `NOTION_TOKEN`을 입력합니다. 공유 링크를 사용하려면 32자 이상의 랜덤값을 `APP_SECRET`에 입력합니다.
3. 서버를 재시작합니다. 웹 주소에 접속한 누구나 로그인 없이 연결된 기록과 사진을 열람할 수 있습니다. 새로고침 버튼으로 최신 기록을 조회합니다. 기록 작성·수정·삭제는 Notion에서만 합니다.
4. `npm test`로 테스트 실행.

## Vercel 배포
새 비공개 GitHub 저장소에 이 폴더 내용을 업로드하고 Vercel에서 Import. Framework Preset Other, Root Directory는 프로젝트 루트, Output Directory `public`(vercel.json 설정). 환경변수 NOTION_TOKEN과 NOTION_DATA_SOURCE_ID를 입력한 뒤 Deploy합니다. 공유 링크를 사용하려면 APP_SECRET도 설정합니다. 실제 배포와 토큰 설정은 사용자의 계정에서 필요. 토큰과 APP_SECRET은 Git에 커밋하지 않습니다.

## 구현
- Notion API 2025-09-03 data source query, 100개 단위 페이지네이션, 최신순, 속성명 기반 매핑.
- 검색/지역/음식/재방문 필터, 지역 및 방문 통계, 카드/목록, 상세 사진 및 후기.
- 공유 링크는 7일 유효한 AES-256-GCM 암호화 스냅샷(서버 DB 추가 불필요), 1~10건 선택. 공개 페이지는 읽기 전용이며 Notion ID·사진·일상/여행 연결은 제외. 링크를 받은 누구나 열 수 있으므로 공유 전 후기를 확인할 것. 개별 공유 취소 기능 없음; APP_SECRET 변경 시 모든 공유 링크 무효화. 긴 공유 링크는 일부 메신저에서 제한될 수 있음.
- Notion에 저장된 사진은 단기 유효 URL을 사용하며 만료 시 새로고침. 외부 이미지도 포함될 수 있음.
- API 오류, 검색 결과 없음, 미설정 데모 처리. 데모에는 개인 데이터가 포함되지 않음.
- 공유 후 편집/삭제가 기존 공유 스냅샷에 반영되지 않음.

## 확인 사항
로컬 단위 테스트 및 HTTP 스모크 테스트는 실행 가능. 실제 Notion 통합 토큰과 배포 권한이 제공되지 않아 라이브 연동/배포 검증은 별도 필요. 기존 Notion DB와 기존 웹앱 코드는 변경하지 않음.
